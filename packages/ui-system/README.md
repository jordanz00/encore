# @encore/ui-system

Apple-grade UI tokens, motion, and **state-aware** React components for Encore.

## Install (monorepo)

```json
"@encore/ui-system": "workspace:*"
```

## CSS

```css
@import "../packages/ui-system/styles/ui-system.css";
```

## Docs

[docs/ENCORE-UI-MOTION-SYSTEM.md](../../docs/ENCORE-UI-MOTION-SYSTEM.md)

## Principles

- No animation without real state
- 8pt grid only
- WCAG 2.2 AA focus + reduced motion
- Cuban filter: no visual noise without ROI
